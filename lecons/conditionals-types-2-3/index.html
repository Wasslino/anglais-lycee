À quoi ça sert

Type 0 : une vérité générale, toujours vraie. Type 1 : une situation réelle et possible dans le futur. Type 2 : imaginer une situation irréelle au présent. Type 3 : regretter une situation impossible du passé.

Type 0 : If + Present Simple, Present Simple · Type 1 : If + Present Simple, will + BV · Type 2 : If + Past Simple, would + BV · Type 3 : If + Past Perfect, would have + PP

Exemples

  • If you heat water to 100°C, it boils.
  • If it rains tomorrow, we will stay at home.
  • If I had money, I would travel the world.
  • If she had studied, she would have passed the exam.
  • If I were rich, I would buy a big house.

Mots-signaux

Type 0 : If + Present Simple, Present Simple · Type 1 : If + Present Simple, will + BV · Type 2 : If I were you… · Type 3 : If + had + PP · would have + PP

Piège d'examen : Après if, jamais de « would » dans la subordonnée : « If I would have money » est faux. Le would est dans la principale.

Wish / If only

Wish exprime un souhait ou un regret : au présent, on voudrait que ce soit différent maintenant ; au passé, on regrette ; ou une plainte, on voudrait que quelqu'un change. If only = I wish, plus fort.

Wish présent : I wish + Past Simple · Wish passé (regret) : I wish + Past Perfect · Plainte : I wish + would + BV · If only + Past Simple / Past Perfect

Exemples — Wish / If only

  • I wish I had a car.
  • I wish I were rich.
  • I wish I had studied harder.
  • I wish you would stop talking.
  • If only I had listened to my teacher !

Mots-signaux — Wish / If only

I wish / If only · Past Simple (présent) · had + PP (passé) · would + BV (plainte)

Piège d'examen : Après wish, jamais de Present Simple pour un souhait présent : « I wish I have a car » est faux, dis « I wish I had a car ». Et jamais « would have » après wish : « I wish I would have studied » est faux, dis « I wish I had studied ».

Mini-exercice corrigé

  1. Complète : « If you ___ (heat) ice, it melts. »

    Correction : heat — Type 0 (If + Present Simple, Present Simple).

  2. Complète : « If I ___ (have) time, I will help you. »

    Correction : have — Type 1 (If + Present Simple, will + BV).

  3. Complète : « If I ___ (be) you, I would study more. »

    Correction : were — Type 2 (If I were you).

  4. Complète : « If he ___ (leave) earlier, he would have caught the bus. »

    Correction : had left — Type 3 (If + Past Perfect).

  5. Complète : « I wish I ___ (have) a bike. »

    Correction : had — Wish présent (I wish + Past Simple).

  6. Complète : « I wish I ___ (not waste) my time yesterday. »

    Correction : hadn't wasted — Wish passé, regret (I wish + Past Perfect).

  7. Complète : « If only I ___ (listen) to my teacher ! »

    Correction : had listened — Regret passé (If only + Past Perfect).

  8. Complète : « I wish you ___ (stop) making noise. »

    Correction : would stop — Plainte (I wish + would + BV).
